# 课程演示：CSV 报告与离线 PDF

这组材料直接组合程序现有元素，不需要编写或导入新插件。所有数据均为合成数据，不包含真实业务信息或 API Key。

## 1. 准备流程

1. 将整个 `course` 文件夹保存在可写目录中，保留内部目录结构。
2. 双击 `一键准备.cmd`。
3. 准备脚本会在 `prepared/日期时间-随机编号/` 下生成两个 `.flow.xml` 文件，并显示完整路径。
4. 在程序中使用“导入”，选择生成的流程文件。请勿直接导入 `templates` 中尚未替换路径的文件。

准备操作只填入本机输入/输出路径，不读取系统服务设置，也不设置或读取 Key。再次准备会生成新目录，不覆盖已有演示结果。移动材料文件夹后应重新准备和导入。

也可在 PowerShell 中指定一个尚不存在的准备目录：

```powershell
.\prepare-demo.ps1 -OutputDirectory 'D:\CourseDemo\run-01'
```

## 2. AI 演示：CSV → 统计报告 TXT

流程文件：`01-csv-ai-report.flow.xml`。

```text
文件输入（读取 CSV，模式为“文本”）→ AI 文本处理 → 文件输出
```

1. 在系统设置中配置自己的 AI 服务：完整 URL、Model 和 Key。
2. 导入流程后，选中“AI 统计报告”元素，在侧边栏选择刚配置的服务。模板中的服务 ID 有意留空，不绑定任何人的账户。
3. 查看 Prompt、最大 Token（512）和最大响应时间（120 秒）。输入已设为 UTF-8 文本读取，向 AI 传递完整 CSV 文本。
4. 运行流程。结果位于本次准备目录的 `results/ai/AI结果.txt`；重复运行会按输出元素的同名策略增加编号。
5. 按下表人工复核报告。不同服务的措辞和计算结果可能不同；不能把“流程执行成功”当作“统计结论正确”。

| 人工核对项目 | 正确值 |
|---|---:|
| 数据记录数（不含表头） | 3 |
| 总金额 | 1750.50 |
| 研发记录数 / 合计 | 2 / 1400.00 |
| 运营记录数 / 合计 | 1 / 350.50 |
| 最大单笔金额 | 1200.00 |

输入文件为 `data/expenses.csv`，人工核对基准为 `expected-report.txt`。完整公式：`1200.00 + 350.50 + 200.00 = 1750.50`。

本流程演示文件读取、AI 请求和结果保存的组合。它没有新增专门的 CSV 统计计算元素；若报告被 Token 上限截断，可调整 AI 元素配置后重试。

## 3. 离线演示：现成报告 → 改名 → PDF

流程文件：`02-offline-report-pdf.flow.xml`。

```text
文件输入（保留 TXT 原文件）→ 批量改名 → 转为 PDF → 文件输出
```

1. 导入该流程，无需配置 AI 服务或连接网络。
2. 文件输入读取预先编写的 `expected-report.txt`；改名模板为 `课程报告_{x}`。
3. 运行后在本次准备目录的 `results/pdf/课程报告_1.pdf` 查看内容。
4. 检查中文、金额和分页是否正常，确认输入 TXT 仍然保留。

这条流程仅演示已有报告的改名和 PDF 输出，不读取 CSV，也不重新计算统计。TXT 转 PDF 使用程序自带转换能力和字体，不需要 Office。

两个流程的文件输出均为“保留收到的内容”、复制、同名自动编号，输入原件不会被此演示删除。

## 4. 自动验证的范围

源码中的 `tests/CourseDemoSmoke.java` 使用 `127.0.0.1` 上的临时模拟服务和随机假 Key，验证真实 CLI 数据链：CSV 读取 → AI 请求 → 固定模拟响应 → TXT 文件与运行记录。

模拟服务直接返回 `expected-report.txt`，不做智能计算。因此，这项自动验证证明的是数据传输和输出保存，不能证明任何真实模型的统计准确性。真实模型报告仍按第 2 节人工复核。

测试必须运行在专门复制出来的程序目录，标记文件名为 `.course-demo-smoke.marker`，内容为 `FLOW_COURSE_DEMO_SMOKE_V1`；测试会拒绝已有设置文件或程序 JAR 不属于该隔离目录的情况。测试假设置、工件和证据全部留在隔离目录中，不修改平时使用的服务配置。
